# bondwell-privacy

Public web of **Bondwell**, a U.S. savings bond value tracker for iPhone. To be served at
<https://bondwell.baltajmn.dev/> by GitHub Pages from `main`, behind Cloudflare (CNAME `bondwell` to
`baltajmn.github.io`, proxied), like `countwell-privacy`.

| Path | What it is |
|---|---|
| `index.html` | What the app does, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall and in the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `bw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Bondwell`.
